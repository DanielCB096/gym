# App móvil

Aplicación para socios y una vista reducida para entrenadores y personal de mantenimiento.

## Objetivo

- consulta de horario, acceso y cuota
- reserva de clases
- seguimiento de rutinas y progreso
- pagos y administración de membresía
- notificaciones y recordatorios

## Stack sugerido

- React Native
- Expo
- TypeScript
- notificaciones push
- integración con pasarela y acceso por QR

## Requisitos

- autenticación segura
- actualizaciones de perfil y consentimiento
- experiencia simple para usuarios no técnicos
- soporte de baja conectividad y sincronización
