# WhatsApp y comunicación

## Objetivo

Centralizar avisos, recordatorios y confirmaciones con una comunicación efectiva y amigable para el socio y el personal.

## Casos de uso
- recordatorio de pago
- vencimiento de membresía
- acceso manual autorizado
- confirmación de reserva de clase
- notificaciones de mantenimiento y aforo

## Reglas
- las plantillas deben estar aprobadas y parametrizadas
- cada mensaje debe quedar registrable con auditoría
- evitar mensajes duplicados por reintentos

## Recomendación técnica

Integración con WhatsApp Business API o proveedor compatible, con cola y normalización de plantillas.

⚠️ El uso de WhatsApp requiere validación y cumplimiento de políticas del proveedor.
