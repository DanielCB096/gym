# Visión y alcance

## Resumen

El sistema es una solución de gestión integral para un gimnasio en México, orientada a operar con un modelo simple, confiable y escalable. Está diseñado para un solo gimnasio con capacidad de crecimiento, sin forzar un rediseño del núcleo cuando se agreguen servicios adicionales.

## Objetivo del negocio

- centralizar la operación de membresías, accesos, ventas, facturación y personal
- reducir la carga operativa de recepción y administración
- automatizar cobros recurrentes y recordatorios
- cuidar el cumplimiento mexicano en facturación, privacidad y salud

## Alcance del sistema

### Incluye

- gestión de socios y membresías
- cobro recurrente automático
- control de acceso con lógica offline
- clases y reservas
- rutinas y seguimiento
- ventas, inventario y corte de caja
- facturación y reportes financieros
- mantenimiento de equipos
- personal y nómina
- comunicación por WhatsApp, push y correo

### No incluye

- multi-sucursal en la primera fase
- CRM extenso para otras líneas de negocio
- facturación electrónica fuera de México
- administración financiera compleja de varias sedes
- servicios extra de Fase 2 y Fase 3 como parte del MVP

## Usuarios principales

- dueño y administrador
- gerente
- recepcionista
- contador
- entrenador
- personal de mantenimiento
- socio

## Supuestos clave

- el gimnasio opera con un único horario base y una zona horaria definida
- el cobro recurrente se realiza en moneda MXN
- el sistema se conecta con un PAC y una pasarela local de pagos
- la operación de acceso debe seguir funcionando con conectividad limitada

⚠️ Se recomienda validar el alcance con un contador, un abogado y un proveedor de hardware antes de producción.
