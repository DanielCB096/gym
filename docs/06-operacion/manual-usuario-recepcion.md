# Manual de usuario: recepción

## Objetivo

Instruir a la recepción en alta de socios, cobro, acceso y atención básica.

## Funciones clave

- búsqueda de socio
- alta con plan y método de pago
- registro de pago inicial o renovación
- atención de corte de caja
- acceso manual con bitácora

## Reglas de seguridad

- no se debe registrar tarjeta completa
- cada acceso manual requiere motivo y justificante
- no se puede cambiar una membresía sin apoyo de gerente o dueño
