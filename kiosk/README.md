# Kiosco / recepción

Pantalla táctil de autoservicio para check-in, consulta rápida y atención en recepción.

## Objetivo

- entrada rápida por QR, huella o tarjeta
- consulta de socio y cortesía
- pago o registro de acceso manual
- soporte de operación sin internet

## Stack sugerido

- React + TypeScript
- Electron o PWA embebida en tablet
- UI táctil con textos grandes y flujo corto

## Reglas de UX

- máximo 3 pasos por flujo
- textos grandes y contrastes altos
- indicadores de éxito, error y reconexión
- modo degradado con caché local
